# DomDevLabs — Portfólio

Portfólio de projetos de **Jefferson Fabre** (DomDevLabs): automação, extensões Chrome, painéis de dados e apps web.

- Site estático: tudo está em `index.html`
- Para editar projetos: altere o array `PROJETOS` no final do `index.html`
- Para usar prints reais: coloque as imagens em `img/` e preencha o campo `imagem` (ex.: `"img/ata-full.png"`)
